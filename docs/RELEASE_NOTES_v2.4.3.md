# HTRAM Release v2.4.3

## Огляд релізу
Реліз оновлює індикатори живлення та зв'язку з сервером повітряних тривог на екрані кімнатного дашборда.

## Основні зміни

- Блискавку індикатора живлення перемальовано симетрично, щоб вона краще виглядала за низької роздільності.
- Мигалку індикатора зв'язку з JAAM замінено на трикутник зі знаком оклику.
- Логіку та кольори індикаторів не змінено.

## Версії компонентів

- **ESPHome Firmware**: `v2.4.3`
- **GD32 Coprocessor Firmware**: `v1.3.4` (`0x0134`), без змін.
